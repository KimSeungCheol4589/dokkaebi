# 도깨비 문파 홈페이지

도깨비의세계 문파용 팬 홈페이지입니다. 달밤의 한옥 마을과 도깨비불을 배경으로 한 실사풍 랜딩 페이지에 아래 기능이 있습니다.

- **문파 소개**: 문파 이름·레벨, 공지, 전투력 순위, 이번 주 성장왕, 기여 점수 기준표
- **문파원**: 닉네임, 직책, 전투력, 최근 7일 성장, 전투력 점수, 활동 점수, 기여 점수
- **문파창고**: 문파 상점에서 사 둔 물품을 기여 점수로 신청 → 운영진 승인 시 재고와 점수 차감
- **내 정보**: 닉네임·전투력 갱신, 활동별 참여 횟수, 점수 내역
- **도술덱**: 문파원 누구나 도술덱을 올리고(도술 8칸 + 궁극기 1칸. 같은 스타일 3개 이상이면 그 스타일 궁극기, 여러 개면 골라서) 서로 🏮 추천할 수 있습니다. 운영진은 '문파 추천 덱'으로 지정해 맨 위에 보여 줍니다. 덱은 로그인하지 않아도 볼 수 있습니다. 도술 목록은 `src/data/skills.ts` (10/21 패치 기준)에서 고칩니다.
- **방명록**: 손님도 이름을 적어 남길 수 있고, 지우기는 작성한 문파원과 운영진만 할 수 있습니다. 같은 이름으로 30초 안에 다시 쓰지 못합니다.
- **방문자 수**: 하단에 오늘·전체 방문 수를 보여 줍니다. 브라우저마다 하루 한 번만 세고, 개인정보는 저장하지 않습니다.
- **관리** (문주·부문주): 신청 처리, 활동 참여 기록, 가입 승인, 직책 변경(문주만), 창고 물품·재고, 문파 정보, 점수 기준(문주만)

### 기여 점수

```
기여 점수 = 전투력 점수 + 활동 점수 − 창고 사용
```

- **전투력 점수**: 현재 전투력이 속한 구간의 점수가 자동으로 매겨집니다. 기본값은 1만 미만 10점부터 5만 이상 100점까지 6구간입니다.
- **활동 점수**: 요신 토벌령(10), 결계지 방어(10), 미혹의 정원(20), 신기 쟁탈전(20). 각 콘텐츠는 **주 1회(수요일 초기화)** 이며, 운영진이 참여자를 기록합니다. 같은 주에 같은 활동을 두 번 기록할 수 없습니다(DB에서도 막음).
- **주간 참여 현황**: 문파원 페이지에서 주별로 누가 어떤 콘텐츠에 참여했는지 볼 수 있습니다.

### 스크린샷으로 전투력 갱신

게임에는 전투력을 조회할 공식 API가 없어서, 스크린샷의 글자를 읽어(OCR, Tesseract.js) 갱신합니다. 이미지는 브라우저 안에서만 처리되고 서버로 올라가지 않습니다.

- **관리 → 전투력 갱신**: 게임 문파원 목록 화면을 여러 장 캡처해 올리면 닉네임을 찾아 전체 전투력을 한 번에 갱신합니다. 저장 전에 읽은 값을 확인·수정할 수 있습니다.
- **내 정보 → 스크린샷으로 읽기**: 내 캐릭터 화면에서 '전투력' 옆 숫자를 읽어 채웁니다.
- 구간과 점수는 **관리 → 문파 정보**에서 문주가 바꿀 수 있습니다.

## 바로 써 보기 (체험 모드)

```bash
npm install
npm run dev
```

`.env` 가 없으면 **체험 모드**로 실행됩니다. 로그인 화면의 체험 계정 버튼(문주/부문주/문파원/가입 대기자)으로 모든 화면을 둘러볼 수 있고, 데이터는 그 브라우저에만 저장됩니다.

## 실제 운영 설정 (Supabase)

1. [supabase.com](https://supabase.com) 에서 무료 프로젝트를 만듭니다.
2. 대시보드 **SQL Editor** 에 [`supabase/schema.sql`](supabase/schema.sql) 내용을 전부 붙여 넣고 실행합니다.
3. **Project Settings → API** 의 `Project URL` 과 `anon public` 키를 `.env` 에 넣습니다.
   ```bash
   cp .env.example .env
   ```
4. **Authentication → URL Configuration** 의 Site URL 을 홈페이지 주소로 바꿉니다. (인증 메일 링크가 여기로 돌아옵니다.)
5. 문주가 **가장 먼저 가입**하세요. 첫 가입자는 자동으로 문주가 되고, 이후 가입자는 운영진이 승인해야 합니다.

> 이메일 인증이 번거로우면 Authentication → Providers → Email 에서 *Confirm email* 을 끌 수 있습니다.

## 권한 규칙

| | 비로그인 | 가입 대기 | 문파원 | 부문주 | 문주 |
|---|:-:|:-:|:-:|:-:|:-:|
| 문파 소개·문파원 목록 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 기여 포인트 보기 | | | ✅ | ✅ | ✅ |
| 창고 신청 | | | ✅ | ✅ | ✅ |
| 가입 승인·포인트 지급·창고 관리·신청 처리 | | | | ✅ | ✅ |
| 직책 변경 | | | | | ✅ |

규칙은 화면이 아니라 DB(RLS 정책과 RPC 함수)에서 검사하므로 화면을 우회해도 지켜집니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Source** 를 *GitHub Actions* 로 바꿉니다.
2. **Settings → Secrets and variables → Actions** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 를 등록합니다.
3. `main` 에 푸시하면 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 이 빌드해서 배포합니다.

## 구조

```
src/
  pages/        화면 (Home, Members, Warehouse, MyPage, Admin, Login)
  components/   레이아웃, 메인 비주얼(Hero)
  assets/       메인 이미지, 로고
  lib/          types, supabaseBackend(실제 DB), demoBackend(체험 모드), auth
supabase/schema.sql   테이블, 권한(RLS), 창고 신청/승인 함수
```

## 참고

- 글꼴: Noto Serif KR, Noto Sans KR (Google Fonts, SIL OFL 1.1)
- 메인 이미지(`src/assets/hero*.webp`)는 AI(Higgsfield, GPT Image 2.5)로 새로 만든 그림입니다.
- 창고 물품 아이콘(`src/assets/items/`)은 게임 문파 상점 화면에서 잘라낸 것으로, 권리는 원저작자(슈퍼캣·카카오게임즈)에게 있습니다.
- 도깨비의세계 공식 사이트가 아닌 문파 팬 홈페이지입니다.
